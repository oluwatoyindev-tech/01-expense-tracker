# Expense Tracker

Track, categorise and report personal expenses from the command line, stored in SQLite.

## Run

```bash
python expense_tracker.py
```
No dependencies — pure standard library. Requires Python 3.8+.

## Built with

Python 3, standard library (SQLite / tkinter)
